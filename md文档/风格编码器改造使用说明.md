

# 风格编码器改造使用说明

> 本说明对应分支 `f+style`，核心改动是把原「冻结 CLIP ViT-B/32 + 224 tiling」风格编码器替换为 **自训 ConvNeXt-T + 整图输入 + 前景感知聚合**，并支持 zero-shot 新风格泛化。

---

## 1. 快速开始

### 1.1 环境准备

- Python ≥ 3.9，PyTorch ≥ 2.0
- 依赖与主项目一致，额外需要：`scipy`、`tqdm`、`Pillow`、`torchvision`
- 建议先确认能正常导入：

```bash
python -c "from models.style_encoder import ConvNeXtStyleEncoder; print('ok')"
```

### 1.2 数据目录约定

```
data_root/
  print/          # 打印体公式图
  style0/         # writer 0 手写公式图
  style1/         # writer 1 手写公式图
  ...
```

关键约定：**同名文件在不同 style* 目录下代表同一公式**，writer 标签自然等于目录名。

## 2. 核心链路改动一览

| 文件 | 改动要点 |
|------|----------|
| `models/style_encoder.py` | 新增 `ConvNeXtStyleEncoder`，stem stride 改为 2，总 stride=16，输出 M=4、D=768 |
| `data/transforms.py` | 新增 `preprocess_style_image`、`batch_style_images`，整图缩放 + padding 到 [-1,1] |
| `data/dataset.py` | `I_s` 返回 tensor + `valid_mask`；`bucket_collate` 同步输出 mask |
| `models/pipeline.py` | 支持在线编码，CFG dropout 行为不变 |
| `inference/inferencer.py` | 推理时风格图走新预处理 |
| `train/trainer.py` | 解包新 batch 格式并把 mask 送到 device |
| `train/optimizer.py` | 支持 `style_backbone_lr_scale`，阶段 C backbone 可用更小学习率 |
| `config/default.yaml` + `config/config_loader.py` | 新增 ConvNeXt 配置项 |

旧版 `TiledCLIPStyleEncoder` 已删除，但 `build_style_encoder` 会按配置自动选择架构。

## 3. 三阶段训练流程

### 阶段 A：DINO 自监督预训练 backbone

目标：用有/无标签风格图做自监督预训练，学习通用笔迹表征。

```bash
python scripts/pretrain_style_dino.py \
    --data_root /path/to/data \
    --output_dir ./checkpoints/style_dino \
    --image_height 64 \
    --max_width 512 \
    --batch_size 128 \
    --epochs 100 \
    --lr 5e-4 \
    --device cuda
```

关键参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data_root` | `./data` | 数据根目录，需包含 `style*/` 或自定义无标签路径 |
| `--unlabeled_roots` | `[]` | 额外无标签数据集路径列表，JSON 格式如 `'["a","b"]'` |
| `--image_height` | 64 | 风格图缩放后的基准高度 |
| `--max_width` | 512 | 最大宽度，超出则裁剪 |
| `--batch_size` | 128 | 每批样本数 |
| `--epochs` | 100 | 训练轮数 |
| `--lr` | 5e-4 | 学习率 |
| `--device` | `cuda` | 训练设备 |

输出：
- `checkpoints/style_dino/dino_backbone_final.pt`：backbone 权重
- `checkpoints/style_dino/dino_projector_final.pt`：DINO projector 权重（阶段 B 可丢弃）

### 阶段 B：对比 + 度量学习微调

目标：用有标签风格图训练 writer-level 判别能力，并分离「风格」与「内容」。

```bash
python scripts/train_style_encoder.py \
    --data_root /path/to/data \
    --dino_checkpoint ./checkpoints/style_dino/dino_backbone_final.pt \
    --output_dir ./checkpoints/style_encoder \
    --batch_size 256 \
    --epochs 100 \
    --device cuda
```

关键参数：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data_root` | `./data` | 有标签数据根目录 |
| `--dino_checkpoint` | null | 阶段 A backbone 路径 |
| `--output_dir` | `./checkpoints/style_encoder` | 输出目录 |
| `--batch_size` | 256 | 每批样本数 |
| `--epochs` | 100 | 训练轮数 |
| `--lr` | 1e-3 | 学习率 |
| `--use_arcface` | false | 是否启用 ArcFace margin 损失 |
| `--device` | `cuda` | 训练设备 |

输出：
- `checkpoints/style_encoder/style_encoder_final.pt`：完整风格编码器权重（阶段 C 初始化用）
- `checkpoints/style_encoder/projection_head_final.pt`：对比学习投影头（推理时丢弃）

### 阶段 C：完整 DiTtolatex 训练

把阶段 B 的风格编码器接入完整扩散 pipeline：

```bash
python main.py --config config/default.yaml
```

需要先在 `config/default.yaml` 中设置：

```yaml
model:
  style_encoder:
    use_convnext: true
    image_height: 64
    max_width: 512
    pretrained: true
    stage_b_checkpoint: "/path/to/checkpoints/style_encoder/style_encoder_final.pt"
```

阶段 C 优化器默认对 `style_encoder.backbone` 使用 `style_backbone_lr_scale=0.5`，其余模块使用主学习率，可在配置中调整。

## 4. 数据增强预览

`scripts/preview_style_augmentations.py` 用于在 `data/test` 等样本上快速预览 5 种笔迹风格增强效果：

- 笔画粗细（Stroke Thickness）
- 倾斜角（Slant Angle）
- 字高/字宽（Character Height/Width）
- 圆润度（Roundness）
- 连笔程度（Ligature）

### 用法

```bash
python scripts/preview_style_augmentations.py \
    --input_dir data/test \
    --output_dir preview_output
```

输出：`preview_output/{原图名}_augment_preview.png`，每张图是一个网格，行对应增强类型，列对应不同强度/方向，第一列为原图。

`preview_output/` 已加入 `.gitignore`，不会被提交。

## 5. 关键配置项说明

`config/default.yaml` 中 `model.style_encoder` 相关字段：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `use_convnext` | true | true=用新版 ConvNeXt；false=回退旧版（已删除，勿用） |
| `image_height` | 64 | 风格图缩放后的基准高度 |
| `max_width` | 512 | 最大宽度，训练时超出随机裁剪，推理时居中裁剪 |
| `pretrained` | true | 是否加载 ImageNet-1K 预训练 backbone |
| `fg_threshold` | 0.0 | 前景 mask 阈值，[-1,1] 中 ≤ 该值视为前景 |
| `num_heads` | 12 | 聚合头 cross-attention 头数 |
| `dropout` | 0.0 | 聚合头 dropout |
| `stage_b_checkpoint` | null | 阶段 B 输出路径，阶段 C 初始化用 |

训练相关：

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `training.style_backbone_lr_scale` | 0.5 | 阶段 C 中 style_encoder.backbone 学习率 = lr * scale |

## 7. 常见问题

**Q1：阶段 A 从零开始训练很慢？**
A：若环境无法下载 ImageNet 预训练权重，`pretrained=true` 会退化为随机初始化，建议把 epochs 提高并增大 batch_size。

**Q2：`fg_threshold=0.0` 含义？**
A：风格图归一化到 [-1,1]，白底约为 +1，墨迹约为 -1。`value <= 0.0` 的像素被视为前景。

**Q3：阶段 B 的 ArcFace 损失要不要开？**
A：默认只使用 SupCon。若 writer 数量多、风格区分度低，可尝试 `--use_arcface` 增强判别性。

**Q4：预览脚本依赖中文字体？**
A：不依赖中文字体，标签使用英文；若无 arial.ttf 会自动回退到默认字体。
